# Publication notes

This package is a curated source publication produced from a larger local research archive. The following are intentionally withheld: virtual environments, Python cache, historical reports and source captures, SQLite databases (including review-session history), transient watchlists, raw creator metadata exports, and detailed evidence-hardening files. Private measurement artifacts are not re-created. No frozen algorithms or application code were changed for this packaging pass.

The published `portfolio/demo/verified_facts.json` is a historical verification record, not a claim that these files are present or freshly reverified. Some archived phase notes reference paths in the withheld reports directory and may therefore contain nonfunctional local references; the primary README and current docs explain this gap.

Before release, review ownership and permitted use of the source code, third-party material, screenshots, generated illustration and the datathon name; choose an explicit license only when intended.
