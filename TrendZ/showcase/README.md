# TrendZ Showcase

**Suggested description:** A beauty trend intelligence research prototype that
connects public search/content evidence to source-backed Product Fit, reviewed
creator candidates and deterministic campaign scenarios. Built with Flask,
SQLite and vanilla JavaScript, with provenance, explicit abstention, frozen
evaluation sets and a provider-ready grounded assistant boundary. Inspired by
the L'Oreal Datathon 2025 collaboration with Monash; not an official L'Oreal product.
